# Bitcoin Research Archive

This archive preserves historical Bitcoin trading experiments,
including unsuccessful strategies.

## What's included

- Bitcoin momentum backtest
- Bitcoin price-pattern research
- Original Overton historical test
- Overton recovery experiment
- Simplified ReinforcedAverage / NDAX-cost experiment
- Simplified TrendRider experiment
- Daily breakout frozen validation program
- Original validation freeze record
- Historical findings and limitations

See [FINDINGS.md](FINDINGS.md) for numerical results.

## Important limitations

- All results are simulations, not live profits.
- Historical profitability does not prove future profitability.
- Some strategies were revised after earlier results were examined.
- The NDAX-labelled experiment does not establish actual NDAX execution costs.
- Several programs require historical Coinbase BTC/USD data.
- Some archived programs depend on files in the parent project folder.
- The frozen validation script is preserved for historical reference.
  Its original source fingerprints and folder structure must be
  respected; it is not independently runnable from this archive.
- Syntax checks and preliminary privacy scans have been performed,
  but a full security and reproducibility audit is not complete.

No API credentials, live trading configuration, or active bot
services are intentionally included.

This material is for research and education, not financial advice.
